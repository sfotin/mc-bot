# mc-bot

Minecraft-бот (1.12.2, Forge) на `mineflayer` для автоматизации построек по
JSON-схемам: ходьба, установка одиночных блоков, выкладывание целых схем
через мировые команды (`/fill`, `/setblock`) с троттлингом и
автопереподключением.

Два режима запуска:

- `index.js` - бот в мире (`mineflayer`): подключается, слушает чат-команды
  (`!goto`, `!place`, `!build`, `!stop`) и физически ставит блоки.
- `index-cmd.js` - "сырой" клиент без модели мира: рассылает мировые
  команды (`/fill`/`/setblock`) от имени оператора/OP на сервере. Умеет
  строить схему (с поворотом на 90/180/270 и опциональной расчисткой
  площадки) или зачищать произвольный объём (`--wipe`).

## Настройка

1. `npm install`
2. Скопируй `.env.example` в `.env` и укажи адрес своего сервера:

   ```
   cp .env.example .env
   ```

   Обязательно `MC_HOST`; остальные переменные (`MC_PORT`, `MC_USERNAME`,
   `MC_VERSION`) опциональны - см. комментарии в `.env.example`.

## Запуск

```
node index.js
```

```
node index-cmd.js схема.json 100 64 200 --prepare --rotate=90
node index-cmd.js --wipe 100 60 200 150 70 250 --ground=63
```

Подробности флагов - в комментариях над `parseCliSchemaRequest`/
`parseCliWipeRequest` в [index-cmd.js](index-cmd.js).

## Схемы построек

JSON-массив объектов `{ "x": 0, "y": 0, "z": 0, "block": "stone" }` (или
`"stone:1"` для metadata), координаты относительные - см. примеры в
[schemas/](schemas/).
