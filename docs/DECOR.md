# DECOR.md — справочник декора «МС город» (Minecraft 1.12.2)

Справочник ванильного декора, по которому генерируются схемы для бота. Формат схем — BOT.md §6, стиль и районы — CITY.md.
Статус элементов: «не проверено в игре», если не указано иное. Первая проверка — постановкой на сервер.

## 0. Соглашения
- Лицевая сторона схемы — юг (+Z). Стена, к которой приставлен предмет, лежит на z = −1 и в схему не входит. y=0 — первый блок над полом (для мебели).
- Для крупных элементов (фонтаны, статуи) слой y=0 — это уровень грунта/мостовой: схема заменяет его; origin.y = уровень этого слоя; запуск без --prepare.
- Метки: [блоки] — /setblock и /fill, бот умеет сейчас; [NBT] — нужны данные блока; [сущность] — нужен /summon. Бот пока не умеет [NBT] и [сущность] — см. §13.
- Элементы до ~50 блоков — JSON прямо здесь; крупнее — поэтажный план ASCII здесь + генератор в tools/decor/ (он же проверяет воду и опоры).
- Проверка: `python3 tools/decor/decor_check.py` — все JSON этого файла; `decor_check.py --schema ФАЙЛ [--terrain below|y0]` — любая готовая схема; генераторы проверяют себя сами при запуске. Проверяются: вода (правило 1.12), опоры, пары (двери, кровати, double_plant), падающие блоки (`sand`, `gravel`, `concrete_powder`, `anvil`, `dragon_egg` — только на твёрдую опору, поставленную раньше или той же командой). Порядок постройки берётся из самого бота: `tools/decor/send_order.js` вызывает `buildFillCommands` из `lib/fill-plan.js` (нужны node и node_modules репозитория, `.env` не нужен). Проходимость (BOT.md §12) к декору не применяется.
- Ловушки имён 1.12.2: дубовый забор `fence` (не oak_fence); дубовый люк `trapdoor` (других деревянных люков нет, только `iron_trapdoor`); дубовая дверь `wooden_door`; калитка `fence_gate`; деревянные плиты `wooden_slab:N`; каменные `stone_slab:N` (0 камень, 1 песчаник, 3 булыжник, 4 кирпич, 5 каменный кирпич, 6 адский кирпич, 7 кварц; +8 верхняя половина); гладкий камень блоком `double_stone_slab:8`, гладкий песчаник `double_stone_slab:9`; нить-блок `tripwire` (string — это предмет).

## 1. Справочник ориентаций
Бот при --rotate пересчитывает только: ступеньки, факелы, кнопки, рычаг, ladder/chest/furnace, нижние половины всех *_door (BOT.md §7). Для остальных направленных блоков metadata ниже задаются вручную под каждую сторону.

| Блок | Metadata |
|---|---|
| trapdoor, iron_trapdoor | биты 0-1 facing: 0 C, 1 Ю, 2 З, 3 В; +4 открыт; +8 верхняя половина. Открытый люк лежит у края, противоположного facing: :4 у южного края клетки, :5 у северного, :6 у восточного, :7 у западного. Опора не нужна (с 1.9) |
| bed | ноги: 0 Ю, 1 З, 2 С, 3 В; изголовье: +8, в клетке по направлению facing от ног. Цвет — в NBT, без NBT красная |
| skull | 1 на полу; 2-5 на стене (С, Ю, З, В — куда смотрит лицо). Тип и поворот на полу (Rot) — NBT; без NBT скелетный череп, Rot=0. Опора не нужна |
| tripwire_hook | 0 Ю, 1 З, 2 С, 3 В — куда торчит; крепится к блоку с обратной стороны |
| dropper, dispenser | 0 низ, 1 верх, 2 С, 3 Ю, 4 З, 5 В — куда смотрит лицо |
| hopper | 0 вниз, 2-5 вбок (С, Ю, З, В) |
| end_rod | 0 вниз, 1 вверх, 2 С, 3 Ю, 4 З, 5 В |
| *_glazed_terracotta | 0 Ю, 1 З, 2 С, 3 В — поворот рисунка |
| double_plant | низ: 0 подсолнух, 1 сирень, 2 высокая трава, 3 папоротник, 4 куст роз, 5 пион; верх: 8 |
| *_door | низ: 0 В, 1 Ю, 2 З, 3 С (закрытая дверь — у края, противоположного facing); верх: 8 петля слева, 9 справа («слева» — при взгляде по направлению facing) |
| torch, redstone_torch | 1 В, 2 З, 3 Ю, 4 С — куда смотрит; опора — блок с обратной стороны (torch:1 висит на восточной грани блока, стоящего западнее); 5 — на полу |
| кнопки | 0 потолок, 1 В, 2 З, 3 Ю, 4 С (куда смотрит; опора — с обратной стороны), 5 пол; +8 нажата |
| lever | 1-4 на стене, как кнопки; 5, 6 на полу; 0, 7 на потолке; +8 включён |

Порядок постройки (BOT.md §4.2–§4.4): бот шлёт команды в три прохода — 1) твёрдые блоки боксами снизу вверх (при равной высоте — в порядке файла); 2) крепящиеся (список `ATTACHED_BLOCK_NAMES` в `lib/fill-plan.js`) по одному, в порядке файла; 3) вода и лава боксами снизу вверх. Отсюда: опоры снизу встают раньше автоматически; в файле важно только — у каждой двери низ сразу перед верхом, ноги кровати сразу перед изголовьем. double_plant: низ и верх попадают в разные слои — рядом с нижней половиной на том же слое ничего не ставить.

## 2. Мебель
Все [блоки], «не проверено в игре», если не указано иное.

### 2.1 Стол обеденный 3×2
Кафе, дома, рестораны. Размер 3×1×2. Перевёрнутые ступеньки дают ножки по краям, между ними — верхняя плита; столешница на высоте 1,0 — под стул-ступеньку. Поворачивается сам.
Вариант «со скатертью»: `carpet:0` на y=1 во все 6 клеток. Палитры: ель `spruce_stairs`+`wooden_slab:9`, берёза `birch_stairs`+`:10`, тёмный дуб `dark_oak_stairs`+`:13`, кварц `quartz_stairs`+`stone_slab:15`.
```json
[{"x":0,"y":0,"z":0,"block":"oak_stairs:5"},{"x":1,"y":0,"z":0,"block":"wooden_slab:8"},{"x":2,"y":0,"z":0,"block":"oak_stairs:4"},
 {"x":0,"y":0,"z":1,"block":"oak_stairs:5"},{"x":1,"y":0,"z":1,"block":"wooden_slab:8"},{"x":2,"y":0,"z":1,"block":"oak_stairs:4"}]
```

### 2.2 Высокий столик
Бар, уличное кафе. Размер 1×2×1. Нажимная плита в 1.12 ставится на забор. Варианты: `nether_brick_fence`+`stone_pressure_plate`; `heavy_weighted_pressure_plate` (плита выше забора — движок поставит её после).
```json
[{"x":0,"y":0,"z":0,"block":"fence"},{"x":0,"y":1,"z":0,"block":"wooden_pressure_plate"}]
```

### 2.3 Стул
Размер 1×1×1. Поворачивается сам. Сидящий смотрит на юг `:3`, на север `:2`, на восток `:1`, на запад `:0`. За столом 2.1: с севера `:3`, с юга `:2`.
```json

```

### 2.4 Кресло
Размер 3×1×1. Подлокотники — открытые люки (бот их не поворачивает). Кресло смотрит на юг: ступенька `:3`, люки З `:6` / В `:7`; на север: `:2`, люки `:6`/`:7`; на восток: `:1`, люки С `:4` / Ю `:5`; на запад: `:0`, люки `:4`/`:5`.

## 3. Уличная мебель
### 3.1 Пляж
#### Пляжный зонт
Природный пляж набережной, бассейны, летние кафе. [блоки], статус: «проверено в игре (вручную)», через бота ещё не ставили. Размер 3×3×3. Ствол `birch_fence`, купол — ковры шахматкой (`carpet:1` центр и углы, `carpet:4` рёбра), под боковыми коврами — `tripwire` (нить держится в воздухе, а ковру достаточно любого блока снизу). Нити ниже ковров — движок ставит их раньше. Симметричен, поворачивается свободно.
Палитры: синий+белый `carpet:11`+`carpet:0`; красный+белый `carpet:14`+`carpet:0`. Большой 5×5: ствол из 3 заборов, 24 нити, 25 ковров. Невидимый вариант опоры: `barrier` вместо нити — только при стволе из 3 заборов (у барьера есть коллизия), ломается только в креативе.

## 13. Потребности к боту
[NBT]: тип и поворот черепа (SkullType, Rot); содержимое цветочного горшка; цвет кровати кроме красного; текст табличек; основа и узоры флагов.
[сущность]: рамка (с предметом/картой), картина, стойка для брони, мобы.
Код (без NBT):
- в поздний проход (опора сбоку или «на чём угодно»): `flower_pot`, `wall_sign`/`standing_sign`, `heavy_weighted_pressure_plate`/`light_weighted_pressure_plate`;
- `waterlily` — нужен проход ПОСЛЕ воды/лавы (сейчас кувшинки ставятся до воды и могут отвалиться);
- `double_plant` — ставить верх сразу за низом (сейчас сортировка по Y их разделяет);
- при --rotate пересчитывать: `trapdoor`/`iron_trapdoor`, `bed`, `skull` 2-5, `tripwire_hook`, `dropper`/`dispenser`/`hopper` (вбок), `end_rod`, `*_glazed_terracotta`, `wall_sign`, `cocoa`;
- пары подряд: у каждой двери низ → верх; кровать ноги → изголовье (правило для генераторов; decor_lib проверяет по реальному порядку команд).
